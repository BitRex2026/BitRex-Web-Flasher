How it works

Four steps, about two minutes.

1

Connect

USB-C data cable from your PC to the USB port of the T-Display-S3 module.

2

Connect serial

Press a flash button, pick the board's serial port in the browser popup.

3

Flash

The browser flashes the mode you picked on the card — Update keeps your settings, Factory erases the chip first and reinstalls everything.

4

Mine

Board reboots → join WiFi / plug Ethernet → open the device's IP for AxeOS.

Troubleshooting

The three issues that cover 99% of cases.

No serial port appears

Use a USB-C data cable (charge-only cables have no data lines). If it is still missing: hold BOOT, tap RST, release BOOT — the board is now in download mode — and press the flash button again.

Flash fails or stuck at “Connecting…”

Close any program using the port (Arduino IDE, PuTTY, esptool). Then retry with BOOT held as above. If it still fails, run the flash once with Erase device enabled for a clean install — note this wipes your WiFi settings.

What is the difference between “Update” and “Factory”?

Update (keep settings) — flashes only the app + Web UI partitions. Your pools, WiFi, stats and settings stay intact. Use this for upgrading an already-running miner.

Factory (full reset) — erases the whole chip first, then writes the bootloader and every partition. This is the equivalent of flashing the esp-miner-factory-… image. Use it for the very first flash or to recover a broken board. ⚠️ It wipes all settings and the board starts over in setup mode.

Board boots but no Ethernet

Check the sandwich is fully seated (board ⇄ adapter ⇄ module). The top bar icon switches from the WiFi glyph to the Ethernet glyph as soon as the W5500 gets an IP. On the Gamma build, this firmware is for LGA rev2.2 only.
